# Relational Belief Compilation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce the smallest verified local experiment supporting a go/no-go decision about joint representation, small-model learning, and auxiliary policy supervision, with a negative result accepted as completion.

**Architecture:** Ordinary Python compilers emit complete six-variable beliefs or exact supports, and one validated Boolean executor evaluates reusable policies. A local CLI advances through evidence gates, with public/private data separation, frozen statistical choices, measured resource limits, and deterministic replay. Learned and MLX dependencies are loaded only when a surviving gate requires them.

**Tech Stack:** Native arm64 Python 3.11/3.12, NumPy, SciPy, pytest, PyYAML; conditional PyTorch/Transformers/Hub/safetensors and optional MLX-LM. Exact package/model revisions are resolved and tested during setup.

**Spec:** [2026-09-28-rbc-design.md](../specs/2026-09-28-rbc-design.md). Read both documents before execution. This plan has not been executed; unchecked steps do not imply missing research results.

## Global Constraints

- Work stays on the current branch, `main`; use meaningful local commits.
- The logic kernel supports 1–12 variables; the learned head supports exactly six.
- Total experiment compute after installation/downloads: 180 measured minutes. Local-LLM inference: 60 measured minutes within total. Single optional encoder repair: 30 measured minutes within total.
- Nondependency core downloads: 500 MB, decimal bytes. Optional LLM model downloads: additional 6 GB, decimal bytes.
- Encoder/LLM route memory ceilings: 8 GiB/12 GiB, lowered to leave at least half physical memory for the OS/other apps.
- Encoding: float32, batch 16 initially, `num_workers=0`, maximum 256 tokens including specials. No silent truncation.
- Reference/calibration/statistics: CPU NumPy/SciPy float64. Optional libraries import only inside their backend paths.
- Use seed 17 for development training; reserve 29 and 43 for post-G2 sensitivity. Never pool seeds as independent cases.
- The main accepted-error target is 2%. Alpha grid: `{0.005,0.01,0.02,0.05}`. Direct threshold grid: `{0.70,0.80,0.90,0.95,0.98,0.99,0.995,1.0}`.
- Development selection requires empirical accepted error at most 1% and at least 50 accepted cases. Primary bootstrap: 2,000 paired source-group resamples, seed 1729.
- No gate may be relaxed after looking at its outcomes. A slice-specific continuation must name that slice and narrow the eventual claim.
- No paid APIs, cloud machines, gated-license acceptance, private datasets, external actions, generated-code execution, UI, services, database, scheduler, or default 12-variable learning.
- Stop implementation of conditional research components when their gate rejects them. Complete verification and reporting for the supported subset.

## Review Focus

These cross-component failures need explicit tests in the owning tasks:

1. Process interruption between writing arrays and marking a stage complete: resume must detect incomplete artifacts, preserve expenditure, and never reuse a partial bundle (T01, T03, T13).
2. Two writers using the same run ID or path traversal in a run/artifact reference: refuse conflicting/escaping writes without overwriting a completed run (T01, T16).
3. Public text repeats by independent sampling while copied derivatives cross splits: preserve legitimate recurrences and reject actual copied-group leakage (T05).
4. A softmax rounds a probability to 1.0 or two devices straddle a set threshold: avoid false certainty and disclose discrete disagreement separately from allclose (T06, T09, T10).
5. A portable replay omits large model weights: verify predictions deterministically, distinguish unavailable weight-byte checks from mismatched bytes, and never claim full model verification without them (T08, T16).
